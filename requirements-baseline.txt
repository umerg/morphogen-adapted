# Working environment for running MorphoGen as a dendrite_gen baseline.
#
# The shipped requirements.txt is a raw `pip freeze` containing ~15 unusable
# local paths (`@ file:///croot/...`), omits plyfile (imported by sub_process.py),
# and pins torch 2.0.0+cu118 while the README says 1.8.2. It cannot be installed.
#
# These versions are verified working on macOS/CPU for the offline stages
# (data conversion, reconstruction, metrics). The DDPM training stage needs a
# CUDA host; install the matching torch build there instead of the line below.
#
# REQUIRES PYTHON >= 3.10. Python 3.8 caps torch at 2.4.1 and numpy at 1.24 and
# cannot satisfy this file; the upstream README's python==3.8.5 refers to the
# authors' 2023 environment.
#   conda create -n MORPHOGEN python=3.10 -y
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cuXXX
#   pip install -r requirements-baseline.txt
#
# NOTE: no CUDA extension is required. modules/functional/{voxelization,
# devoxelization}.py provide pure-PyTorch implementations of the only two ops
# DiT-3D needs, so `import DDPM_train` works with no nvcc toolchain. Vendoring
# the upstream DiT-3D `modules/functional/src` remains optional, purely for speed.

# TORCH IS DELIBERATELY NOT PINNED HERE.
#
# Pinning it made `pip install -r` silently replace a CUDA-matched build with a
# default-index one compiled against a newer CUDA than the driver, producing:
#   RuntimeError: The NVIDIA driver on your system is too old (found version 12020)
#
# Install torch FIRST, matching the cluster driver, then run this file:
#   nvidia-smi                       # read the CUDA version, e.g. 12.2
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# A cu121 build runs on any 12.x driver. torch >= 2.6 dropped cu121 wheels, so on a
# 12.0-12.3 driver use torch<=2.5.1 (e.g. torch==2.5.1 + torchvision==0.20.1).
# Verified: torch 2.13.0 on macOS/CPU (offline stages). The Linux/CUDA build is
# whatever matches your driver -- nothing in this fork depends on a specific one.

timm>=1.0             # DiT blocks (models/dit3d.py)

# Lower bounds, not exact pins: the versions that resolve differ between macOS
# (offline stages) and Linux/CUDA (training), and nothing depends on a patch release.
numpy>=1.24
scipy>=1.10
scikit-learn>=1.3
networkx>=3.0

# point-cloud / mesh IO
